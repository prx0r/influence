## V4 Engine (working)

### Verification Pipeline
1. **Cloudflare registry API** (primary) — `POST /accounts/:id/registrar/domain-check`
   - Authoritative, batch of 20 domains
   - Returns: registrable (true/false), reason (domain_unavailable, domain_premium, extension_disallows_registration)
2. **IANA RDAP bootstrap** (fallback) — 10 TLDs bundled (com, net, org, io, dev, app, xyz, ai, co, sh)
   - 5-second timeout per domain
   - HTTP 200 = TAKEN, HTTP 404 = AVAILABLE

### Status Enum
```
AVAILABLE    — domain is registrable (registry-confirmed)
TAKEN        — domain is registered (registry-confirmed)
PREMIUM      — domain is premium-priced
UNAVAILABLE  — TLD disallows registration
UNSUPPORTED  — TLD not in RDAP bootstrap
UNVERIFIED   — all lookups failed
```

### Proof Receipt Format
```json
{
  "domain": "example.com",
  "status": "TAKEN",
  "proof": {
    "source": "cf_registry",
    "authoritative": true,
    "checked_at": "2026-08-22T...",
    "reason": "domain_unavailable"
  },
  "registrar_links": [...]
}
```

## V1 Spec (from user)

> Give me a domain → tell me whether I can register it right now → prove where that answer came from → give me buttons to go buy/check it.

### V1 Public Surface
- GET /api/check/:domain — Yes
- POST /api/check — Yes, ≤20 domains
- /api/health — Yes
- Web UI — Yes
- Registrar links — Yes
- Verification proof — Yes
- verify_domain MCP — Yes
- Everything else — No

### V1 Acceptance Tests
1. A registered domain can never return AVAILABLE.
2. RDAP/API timeout can never return AVAILABLE.
3. HTTP 429/500 can never return AVAILABLE.
4. Unsupported TLD can never return AVAILABLE.
5. Premium domain is never incorrectly labeled TAKEN.
6. Registry-frozen/reserved domain is not labeled AVAILABLE.
7. Uppercase/trailing whitespace normalize correctly.
8. Malformed domains get deterministic 400 INVALID_DOMAIN.
9. Bulk output exactly matches single-domain output for the same names.
10. Every result contains source + timestamp + authoritative flag.
11. Every outbound registrar link contains the exact encoded domain.
12. Failure at one verification source never gets silently converted into negative evidence.

## Key Learnings

1. **Never rewrite a working landing page** — The backtick template literal approach works. String concatenation with `+ '...'` breaks HTML attribute escaping in JS.
2. **Additive, not destructive** — V4 engine was added alongside V3, not replacing it. This keeps V3 working while experimenting.
3. **Test before deploying** — The button broke twice because of variable scoping issues (`out` variable in `search()` vs `renderAll()`).
4. **Keep the same UI pattern** — Users expect consistency. Don't change the button text, layout, or interaction patterns without good reason.
5. **Cloudflare registry API works** — The `/registrar/domain-check` endpoint provides authoritative results in ~100ms.
