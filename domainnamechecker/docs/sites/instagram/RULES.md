# Instagram — handle rules (official)
Source: Instagram help (username requirements); Graph API has NO availability endpoint.

## Acceptable names
- ≤30 chars, lowercase letters/numbers/periods/underscores.

## Our method
- Anonymous servers: UNKNOWN always (proven: 302/0b identical both ways from datacenters).
- `IG_SESSIONID` passthrough: exact `"username":"{u}"` in profile metadata = TAKEN.
- Never emit AVAILABLE anonymously. Managed actors (Apify/Zyla) are the funded path.
