# storefront — kind: surface

Every influencer gets a store. Content makes the audience, the store
catches the money.

- Intent: attention in, revenue out, all receipted.
- In → out: live endpoint + catalog specs → listings → orders →
  fulfilled goods + payouts.
- Path: setup.social (store subdomain) → listing resources (title,
  price, inventory as desired state; platform readback as observed) →
  order queue with digits → fulfillment → payout with drift guards.
- Needs: instant-influencer or autopilot freak (the brand), clip-farm
  (the ads are just clips), influencer-ops order patterns, money-proof
  rails (see `money-proof.md`).
- Merch line: print-on-demand as a capability-matrix provider like any
  other bridge — quote, bounded grant, provision, readback. Designs come
  from the studio; inventory never sits with us.
- Distribution: own subdomain first, Etsy as a second door (roast.pet
  proves the pattern).
- Status: designed. Next: listing passport kinds, one provider, one
  test order end to end with receipt.
