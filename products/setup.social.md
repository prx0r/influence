# setup.social — kind: infra

Identity provisioning for other products. Everything that ends at an
endpoint starts here.

- Intent: turn a concept into owned, wired identity.
- In → out: concept → handle, domain, zone, mailbox, number, claimed socials.
- Path: L1 observe (verify, map, compare) → L2 acquire (register, move,
  create, provision, claim — all human-gated) → `influencer()` resolution.
- Needs: layer 0 (grants, journal, receipts). Nothing else.
- Feeds: instant-influencer, roast.pet, party-rooms, any future endpoint.
- Status: graph + observe live. Next: registrar compare, zone apply,
  mailbox create, number bridges as passport kinds.
