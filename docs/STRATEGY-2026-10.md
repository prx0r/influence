# Strategy: what is valuable after AI makes software cheap (2026-10-10)

> Saved from research brief. Core thesis: code generation is collapsing in
> cost; reliability, desirability, distinctiveness, and commercial execution
> are not. Invest in layers 3–5 below. Buy/rent layers 1–2.

## Value hierarchy (cheapest → most valuable)

1. **Generation** — code, images, meshes, voices, game prototypes. Rent.
2. **Selection and taste** — which generated thing is desirable. Build (learn loop).
3. **Verification and execution** — does it work, can it be made, does it arrive. Build (gates + compiler).
4. **Distribution and relationships** — repeat customers, characters, audiences, suppliers. Build (operator + entities).
5. **Accumulated proprietary history** — preference signals, character reputation, supplier performance, validated designs, fulfilment outcomes. Build (ledgers + receipts).

## Positions

- **OddHobb:** AI-created digital designs → verified, purchasable physical products.
- **Pogtown:** disposable AI content → persistent characters with audience + commercial value.

Neither requires owning a foundation model, game engine, or general agent framework.

## Flywheels

- **Entertainment:** Create Pog → publish set → Funnier votes → champion → following → merchandise.
- **Manufacturing:** Detect demand → design with AI tools → verify → quote → produce → fulfil → learn costs/quality.

Funnier answers "do people like this?" Compiler answers "can we make and sell it?"

## P0–P3 (Dec 2026)

- **P0:** OddHobb commerce + supplier execution. One personalised product + one multi-supplier gift box paid, made, delivered.
- **P1:** One repeatable comedy format. GLB → performance → MP4 → Funnier → Pogtown profile.
- **P2:** Hardware compiler reference (GlowBase). Second shell reuses same electronics.
- **P3:** Developer opportunity radar. One developer agrees to pilot manufacturing.

## Frozen

General game creation, custom engines, general agent memory, proprietary multiplayer, model training, massive catalogues, advanced robotics, simulated Pogtown society. Unity Spark until API/economics known.

## Pog identity contract (portability)

Small persistent identity (id, creator, name/premise/voice, model/rig refs, performance/relationship/achievement history, product/device links). Rendering engine, harness, model, and game engine can all change; identity + history persist.
