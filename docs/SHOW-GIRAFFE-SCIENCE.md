# SHOW SPEC: Giraffe Hosts Daily Science (working title)

> First show built top-down from comedic theory. Two idiots misinterpret
> real science, occasionally land a weirdly insightful angle. Derived from
> starting hypothesis, not from vibes.

---

## Starting hypothesis (H-SUP-01)

**Superiority with affection:** audiences laugh hardest when they feel
smarter than characters they genuinely like, *and* the characters
occasionally prove smarter than expected (keeps affection from curdling
into contempt).

- Theory parents: `audience_alliance` + `status_reversal` (theories.json)
- Operators: STATUS (invert expert/novice), SELF_AWARENESS (selective),
  AUDIENCE_SUPERIORITY (invite comparison, then betray it)

## Supporting hypotheses

| ID | Claim | Operator | Test |
|---|---|---|---|
| H-PERSP-01 | A confident wrong frame that *almost* fits beats random nonsense | BISOCIATION | audience completes the mapping before the punchline |
| H-WORLD-01 | Committing to the bit's world for 90s+ beats sketch-hopping | RIGIDITY | retention at 60-90s vs format baseline |
| H-GUEST-02 | Expert guest + idiot hosts = status comedy engine | STATUS | guest episodes outperform solo on shares |
| H-INSIGHT-03 | 1 genuine insight per 5 minutes keeps smart audiences loyal | CONTRAST | comment sentiment + return rate |

## Format (validated ladder: pilot 3 → season 12 → franchise)

```
COLD OPEN (0:00-0:20)   Giraffe states today's theory with total confidence, slightly wrong.
PAPER INTRO (0:20-1:00) Real paper/idea (e.g. Levin: cells as agents, minds ingressing).
IDIOT PASS 1 (1:00-2:30) Hosts misinterpret through daily-life lens (giraffe: "so my neck...?").
GUEST OR DEEPEN (2:30-4:00) Validated character auditions inside the format OR expert clip.
INSIGHT BEAT (4:00-4:30) One genuinely correct angle, delivered accidentally.
CALLBACK CLOSE (4:30-5:00) Earlier misinterpretation returns as the button.
```

Duration 5:00 (long-form + 2x 0:30 Shorts cuts per episode).

## Pilot arc (3 episodes)

1. **Levin: minds ingressing** — giraffe concludes his neck is "several minds stacked vertically." Co-host insists digestion is thinking. Insight beat: collective intelligence *does* scale with coordination (true).
2. **Octopus distributed cognition** — hosts argue about who among them is the "arm." Guest slot: validated character auditions.
3. **Slime mould problem-solving** — hosts attempt maze live, fail, blame maze. Insight: failure reveals the algorithm (true).

## JokeBlock mining per episode

For each paper: facts[] (status: confirmed/reported/unconfirmed) →
comic_model (what idiots believe) → operators run_all → premises →
derivations → ledger. Culture heat checked (no stale memes).
Facts never asserted beyond status (epistemic guardrail holds on air).

## Roles

- **Giraffe (host):** confident, credentialed-sounding, wrong with footnotes.
- **Co-host idiot:** lateral misreads, domestic analogies, asks the dumb question the audience has.
- **Guest slot (ep 2+):** validated characters only (graduation ≥ recurring).
- **Science consultant (off-air):** verifies the 1 insight beat is actually true.

## Metrics that validate the FORMAT (not just episodes)

- Retention floor: 45%+ at 1:00 across 3/3 pilots
- Hook variance: cold-open retention within 10pts across episodes
- Insight comments: ≥5% mention the true angle (proves H-INSIGHT-03)
- Return rate: ep2 > 60% of ep1 views
- Cost per episode stable (no cost creep)

## If validated → franchise moves

- Guest pipeline: tested characters audition inside format
- Spinoff topics: audience-voted papers
- Shorts machine: 2 cuts/episode via jevcut-style clipping
- Merch: "I survived giraffe science" (OddHobb, after demand signal)
