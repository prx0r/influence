# Endgame: synthetic entertainment universe with persistent talent

> Saved 2026-10-10 from research brief. When Pogtown stops being "a comedy
> channel" and becomes a Darwinian talent agency for synthetic people:
> characters audition, some die, some become regulars, a few become stars,
> and stars escape into the wider world.

## Graduation pipeline

```
Freaktown creates the character
        ↓
audience validates the character
        ↓
character graduates
        ↓
Influence creates a persistent Character Brand
        ↓
same character now exists across:
YouTube · Instagram · X · podcasts · interviews · live shows · AR · merch
```

Stages: `draft → contestant → recurring → regular → breakout → public_persona`.
Only `public_persona` gets persistent accounts. Make it prestigious — evidence-based:
multiple successful appearances, positive character-specific comments, return
requests, recognizable name, catchphrase adoption, range across material.

## Authority split (frozen)

- **Freaktown** = who the character IS (canon, beliefs, relationships, voice,
  history, behavioral rules). Authority on identity.
- **Influence** = where/how the character APPEARS publicly. Read-only projection
  of identity. Never invents canon.

A character never becomes "whatever performed best on Instagram."

## Four states (keep separate, link them)

1. **Fictional** — what Nolan believes (CharacterGraph).
2. **Public** — what audiences have seen (Influence Public Graph).
3. **Empirical** — what we've learned works (strategy weights).
4. **Commercial** — actual audience demand (sales, subs, revenue).

## Public memory vs character memory

- CharacterGraph = what the character believes/remembers.
- Influence Public Graph = what audiences have seen/published.
- Before posting, check: canonical? publicly established? safe to reveal?
  consistent with current state? Never collapse future narrative possibilities.
