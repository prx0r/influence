## Real bugs found by actual testing

1. **Chat infinite recursion** — bare `tasks` re-entered `handle_chat`
   with the same word (`maximum recursion depth exceeded`). Fixed by
   falling through to handlers instead of recursing. First run logged
   the FAIL with receipt:cdadd398839deb1a; rerun green.
2. **Cloudflare edge 403s Python-urllib UA** — tunnel checks failed
   auth-looking 403s that were edge bot-blocking, not our gate.
   Verified with curl UA swap. Fix: `User-Agent: influence-sweep/1.0`
   on all out-of-band test clients.
3. **Duplicate tunnel processes** — two cloudflared instances on the
   same named tunnel (one from another session). Same config, same
   backend, harmless, but noted: restart hygiene matters.
